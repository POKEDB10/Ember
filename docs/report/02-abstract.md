# Abstract

Ember is a Java desktop messenger and campus social application for an offline, single-laptop demonstration. It uses TLS 1.3 sockets, a bounded length-prefixed protocol, UTF-8 payloads, PBKDF2 password hashing, and CRC-checked WAL storage using JDK APIs. Users can exchange direct and group messages, recover offline messages, reply, react, edit, delete, pin, star, search, forward, and set an expiry. Campus Pulse adds private profiles, follow approval, block/report, image posts, stories, likes, comments, and group polls. GZIP snapshots compact the event log while preserving recovery. A zero-dependency test runner checks live TLS behavior, authorization, expiry, and restart recovery, including Arabic and emoji text. The project is built as a teaching system with code and security claims students can explain.
