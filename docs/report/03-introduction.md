# Introduction

## Background and motivation

Ember is a student-built desktop messenger with a lighter campus social feed. The project gives the team a practical setting to apply Java, Swing, networking, concurrency, validation, and file-based persistence.

## Objectives

- Build an offline desktop demonstration that runs on one laptop.
- Keep the implementation readable and explainable for students who know core Java and Swing.
- Demonstrate a real TLS transport, server-side authorization, and recoverable storage as implementation phases complete.
- Use explicit frame limits, UTF-8 text encoding, and password hashing primitives supported by the JDK.

## Scope

The application is implemented in Java with Swing and JDK APIs only. The team runs one local server and three clients over loopback. Current implementation status is tracked by phase; this document will be revised to match delivered features.
