# Conclusion and future work

Ember now combines direct and group chat with Campus Pulse features, server-side authorization, private-account controls, expiring content, polls, moderation reports, WAL recovery with snapshot compaction, real-TLS attack demonstrations, and a repeatable concurrency stress harness. The project remains a JDK-only Java/Swing teaching application. The client app-image bundles a runtime, while local key material remains separately configured. Potential future work includes virtual threads on a later Java target, SQLite through JDBC, group end-to-end encryption, voice notes, right-to-left layout, and a mobile client.
