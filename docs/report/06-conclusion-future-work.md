# Conclusion and future work

Ember now combines direct and group chat with Campus Pulse features, server-side authorization, private-account controls, expiring content, polls, moderation reports, and WAL recovery with snapshot compaction. The project remains a JDK-only Java/Swing teaching application. Potential future work includes virtual threads on a later Java target, SQLite through JDBC, group end-to-end encryption, voice notes, right-to-left layout, and a mobile client.
