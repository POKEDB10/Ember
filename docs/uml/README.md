# UML diagrams

The five `.puml` files in this folder describe implemented Ember flows and classes. Render them with the PlantUML web editor or a local PlantUML JAR with Graphviz installed. These are documentation tools only; the application has no PlantUML or Graphviz dependency. Compare the diagrams with `ClientController`, `EmberServer.ConnectionHandler`, `StorageEngine`, `WalStorageEngine`, `Message`, `GroupService`, and `SocialFeedService` when reviewing.
